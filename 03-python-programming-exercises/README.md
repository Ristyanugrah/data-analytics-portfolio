# Python Programming Exercises

## Overview
This repository contains Python programming exercises completed as part of my Data Analyst Bootcamp at Dibimbing.id. These exercises are designed to strengthen my understanding of Python fundamentals and problem-solving skills through practical coding tasks.

## Learning Objectives
- Apply conditional statements to solve programming problems.
- Process user input and display output using Python.
- Use f-strings to format output.
- Perform basic arithmetic operations and handle division by zero.
- Practice problem-solving through simple programming scenarios.
- Analyze sales data using Python lists and basic statistical operations.

## Exercises

### Level 1: Python Fundamentals and Logic

**1. Simple Calculator**
- Accepts two numerical inputs from the user.
- Supports addition, subtraction, multiplication, and division.
- Uses conditional statements to determine the selected operation.
- Handles division by zero and invalid operators.

**2. Grade Classification**
- Accepts a student's name and score.
- Classifies scores into letter grades.
- Displays a report using formatted strings (f-strings).
- Provides feedback based on the student's score.

### Level 2: Data Structures

**3. Sales Data Analysis Using Lists**
- Stores daily sales data in a Python list.
- Calculates total and average sales.
- Identifies the highest and lowest sales values.
- Determines the days with the highest and lowest sales.
