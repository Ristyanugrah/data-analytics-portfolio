# Statistical Analysis with Python

## Overview
This notebook explores fundamental statistical concepts using Python. It analyzes customer age and spending data to understand descriptive statistics, probability, relationships between variables, distributions, and standardized scores.

## Learning Objectives
- Calculate descriptive statistics using pandas.
- Understand mean, median, mode, variance, and standard deviation.
- Calculate expected value using probabilities.
- Analyze covariance and correlation.
- Explore data distributions using histograms.
- Calculate and interpret Z-scores.
- Visualize data using Seaborn and Matplotlib.

## Topics Covered

### 1. Descriptive Statistics
- `describe()`
- Mean, median, and mode
- Variance and standard deviation

### 2. Expected Value
- Probability distributions
- Weighted values
- Expected spending calculations

### 3. Covariance and Correlation
- Measuring relationships between customer age and spending
- Interpreting positive and negative relationships

### 4. Data Distribution
- Histograms and KDE plots
- Normal distribution
- Right-skewed distribution

### 5. Z-Score Analysis
- Standardizing numerical values
- Identifying observations above or below the mean
- Interpreting customer spending relative to the dataset

## Tools and Technologies
- Python
- pandas
- NumPy
- Seaborn
- Matplotlib
- Google Colab

## Dataset
The notebook uses a sample customer dataset containing names, ages, total spending, and gender. An additional probability table is used to demonstrate expected value calculations.

## Key Skills
- Statistical analysis
- Probability calculations
- Correlation analysis
- Distribution analysis
- Data visualization
- Statistical interpretation

## Notes
This notebook contains educational examples using a small sample dataset. Statistical interpretations should be treated as exploratory findings rather than general conclusions about all customers.
