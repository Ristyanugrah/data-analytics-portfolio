# Python Algorithmic Problem Solving

## Overview
This repository contains Python algorithmic problem-solving exercises focused on logical thinking, numerical operations, loops, and dictionary-based data grouping.

The notebook explores two coding challenges: reversing an integer while checking 32-bit integer limits and grouping anagrams using sorted characters as dictionary keys.

## Problems Covered

### 1. Reverse Integer
- Extract digits using the modulo operator (`%`).
- Remove the last digit using floor division (`//`).
- Reverse digits using a `while` loop.
- Preserve the original sign of the integer.
- Check the valid 32-bit signed integer range.

### 2. Group Anagrams
- Sort the characters in each word.
- Use the sorted word as a dictionary key.
- Group words that contain the same characters.
- Use loops, conditional statements, and reusable functions.
- Return the grouped anagrams as a list of lists.
