# Python Looping and Reusable Functions

## Overview
This notebook contains practical Python exercises focused on loops, reusable functions, list comprehension, lambda functions, and nested loops.

The exercises demonstrate how to clean raw data, calculate prices after tax, format numerical results, and generate a multiplication table.

## Learning Objectives
- Use `for` loops to process data.
- Create reusable functions to clean raw data.
- Check data types using `isinstance()`.
- Apply list comprehension to transform data.
- Use lambda functions to round numerical values.
- Implement nested loops to generate a multiplication table.

## Exercises

### 1. Data Cleaning with Loops and Functions
Filter a mixed list of numbers and text values to retain only numeric values greater than or equal to 200.

### 2. List Comprehension and Lambda Functions
Calculate prices after applying an 11% tax and round the results to two decimal places.

### 3. Nested Loops
Generate a multiplication table from 1 × 1 through 10 × 10 using nested `for` loops.
