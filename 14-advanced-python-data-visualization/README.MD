# Advanced Data Visualization with Python

## Project Overview

This project explores intermediate data visualization techniques using Matplotlib and Seaborn. Using Seaborn's built-in `tips` dataset, it demonstrates how visual design choices can improve readability and support comparisons across categories and subgroups.

## Objectives

- Improve chart readability and aesthetics.
- Use filled areas to emphasize patterns and comparisons.
- Apply discrete and continuous color mappings appropriately.
- Compare subgroups using faceted visualizations.
- Develop clear and accessible visual communication.

## Tools & Technologies

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook / Google Colab

## Dataset

The project uses Seaborn's built-in `tips` dataset, which contains restaurant bill and tipping information alongside customer and dining attributes.

## Visualization Techniques

1. **Readability & Aesthetics:** Compare default and customized bar charts.
2. **Filled Areas:** Use `fill_between()` to highlight average total bills across days.
3. **Color Mapping:** Apply categorical palettes and continuous color gradients.
4. **FacetGrid:** Compare the relationship between total bills and tips across sex and smoking-status groups.

## Key Learning Outcomes

- Design charts with informative titles and clear axis labels.
- Choose color strategies that match the data type.
- Use filled areas without exaggerating visual differences.
- Compare subgroups through consistent faceted plots.
- Communicate analytical findings clearly to technical and non-technical audiences.

## How to Run

1. Open the notebook in Google Colab or Jupyter Notebook.
2. Install the required libraries if they are not already available.
3. Run the notebook cells in order.

The dataset is loaded directly through Seaborn, so no external dataset file is required.

## Conclusion

This project demonstrates practical techniques for creating clearer, more informative, and more professional data visualizations with Python.
