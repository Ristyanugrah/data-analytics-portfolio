# Data Visualization with Python: Superstore Sales Analysis

## Overview

This project explores data visualization techniques using Python, Matplotlib, Seaborn, and pandas. Using the Sample Superstore dataset, the notebook demonstrates how to visualize order patterns, segment performance, monthly trends, regional quantities, and relationships between sales and profitability.

## Objectives

- Create clear and informative charts using Matplotlib and Seaborn.
- Analyze order counts across shipping modes and customer segments.
- Visualize monthly order trends by customer segment.
- Apply chart labels, annotations, legends, grids, and color palettes.
- Use area charts to highlight trends and comparisons.
- Explore correlations between sales, profit, discounts, and quantities.
- Compare sales and profit distributions across product categories and regions.

## Dataset

The project uses the Sample Superstore dataset, containing order, customer, product, shipping, sales, discount, quantity, and profit information.

The notebook loads the dataset from the Kaggle dataset `vivek468/superstore-dataset-final`.
